### Как сделать у слова первую букву заглавной
В некоторых СУБД есть функция INITCAP() 
В MySQL ее к сожалению нет. 
Пришлось устраивать полную порнуху:
1. Брать первую букву слова
2. Переводить ее в верхний регистр
3. брать весь остальной остаток слова без первой буквы 
4. и склеивать все это

```sql
select
  concat(upper(substring(name, 1, 1)), lower(substring(name, 2))) as name,
  concat(upper(substring(surname, 1, 1)), lower(substring(surname, 2))) as surname
from Directors 
where binary name = lower(name) or binary surname = lower(surname)
order by name;
```
