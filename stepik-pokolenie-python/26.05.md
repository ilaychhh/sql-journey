-- binary - позволяет сравнивать строки с учетом регистра
-- Столкнулся с задачей, где надо отфильтровать поля, в которых в тексте отсутствует верхний регистр 
-- В итоге код такой:

``` sql
SLECT name, surname
FROM Directors
WHERE binary name = lower(name)
  OR binary surname = lower(surname)
ORDER BY name;
```
